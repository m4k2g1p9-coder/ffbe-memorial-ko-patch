FFBE Memorial 한글 패치 Ver.02 (배포판, APK 덧씌우기)

대상: FFBE-Memorial-EN-Global-Events-v208.apk (com.square_enix.ffbejpn)
 - 본인이 가진 원본 APK에 번역을 덧씌워 "<원본이름>-KO.apk"를 새로 만듭니다. 원본 APK는 수정하지 않습니다.
 - 이 패치에는 게임 파일이 들어 있지 않습니다. 글꼴·이미지·스크립트는 "차분"으로만 들어 있어,
   반드시 위의 원본 APK가 있어야 하고 다른 버전의 APK에는 적용되지 않습니다.
 - Windows 10/11 기본 PowerShell만 씁니다.

사용법
 1) run_patch.bat 더블클릭 (또는 원본 APK를 run_patch.bat 위로 끌어다 놓기)
 2) 원본 APK 선택 → 1~2분 뒤 원본과 같은 폴더에 "<원본이름>-KO.apk" 생성
 3) 만들어진 APK를 기기에 설치 (arm64)

설치할 때 꼭 알아둘 것
 - 패치한 APK는 이 PC에서 새로 만든 키로 서명됩니다. 원본 앱 위에는 업데이트로 설치되지 않으므로
   기존 앱을 지우고 설치해야 하며, 그러면 앱 안의 세이브·다운로드 데이터가 사라질 수 있습니다.
 - 서명 키는 %LOCALAPPDATA%\FFBE-KO-Patch\key 에 만들어집니다. 이 폴더를 지우지 않으면 다음 버전 패치를
   데이터를 유지한 채 업데이트 설치할 수 있습니다. 키 파일은 남에게 주지 마세요.

들어 있는 것
 - 번역 사전 304,404항목(게임 데이터·UI·스토리/이벤트 대사). 시즌1(1부) 대사는 영어 그대로입니다.
 - 한글 글꼴(Noto Sans KR, SIL OFL), 한글 UI 이미지, 한글 명패 124장.
 - 이벤트 전투·일본판 메모리 등 그 밖의 배너 그림은 원문 그대로 나옵니다.

문제 해결
 - "delta base mismatch" / 해시 경고: 원본 v208 APK가 아닙니다. 이미 패치된 APK나 다른 버전에는 적용할 수 없습니다.

비공식 팬 번역입니다. 게임과 원문의 권리는 원 권리자에게 있습니다.
